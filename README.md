# Athlegame Esports Website

Premium multi-page Next.js website concept for Athlegame Esports.

## Stack
- Next.js (App Router)
- React
- Tailwind CSS
- Framer Motion

## Pages
- Home
- About
- Team (FIFA-style player cards)
- Divisions
- Achievements
- Contact
- Admin (CMS-ready placeholder)

## Content Management
All editable content currently lives in `lib/data.ts` for quick updates. This can be replaced with a headless CMS (Sanity/Strapi/Payload).

## Run
```bash
npm install
npm run dev
```
